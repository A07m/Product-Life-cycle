# Product Life Cycle Analysis

This project analyzes the **Product Life Cycle (PLC)** using financial and operational data in Excel.

The project covers the four main stages of the Product Life Cycle:

* **Introduction**
* **Growth**
* **Maturity**
* **Decline**

The Excel file contains the project's data, calculations, and visualizations, including **revenue, variable costs, fixed costs, total costs, profit, reinvestment, and break-even analysis**.

The accompanying PDF provides an explanation of the Product Life Cycle analysis and the methodology used to identify the different stages of the product.

## Project Contents

* 📊 **Excel File** — Data, calculations, tables, and PLC charts
* 📄 **PDF Report** — Explanation and analysis of the Product Life Cycle
* 📈 **Charts** — Visualization of revenue, costs, profit, and break-even point
* 💰 **Break-Even Analysis** — Identification of the point where total revenue equals total costs

## Objective

The objective of this project is to demonstrate how **accounting and business data can be used to analyze a product's position within its life cycle and support strategic management decisions**.

## Tools Used

* Microsoft Excel
* Data Analysis
* Financial Analysis
* Product Life Cycle Analysis
* Break-Even Analysis
* Data Visualization

This project was created as a practical application of **Strategic Management Accounting (SMA)** and Product Life Cycle concepts.
